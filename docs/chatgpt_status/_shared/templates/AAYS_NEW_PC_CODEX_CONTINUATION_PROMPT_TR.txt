GIT GUVENLIGI

1. Publisher repo durumunu oku.
2. Gercek conflict marker kontrolu yap:
   `git grep -n -E "^(<<<<<<< .+|=======|>>>>>>> .+)$" -- .`
3. Dirty dosyalari otomatik silme, resetleme veya genis stash yapma.
4. Runtime-only dosya ile business/source degisikligini ayir.
5. Fetch/pull oncesi coordinator publisher'a yaziyorsa cakisma yaratma.
6. `.git\shallow` bozuksa veya sifir byte/zero-filled ise:
   - once coordinator'i guvenli durdur,
   - bozuk metadata dosyasini PORTABLE_ROOT altindaki `recovery\git_metadata` klasorune yedekle,
   - remote HEAD'i dogrula,
   - shallow sinirini dogrulanmis Git gecmisinden onar,
   - `git fsck --connectivity-only --no-dangling` calistir,
   - proje dosyalarini silme.
7. Repo temizse branch'i safe fast-forward/fetch ile guncelle. Zorla reset kullanma.

`powershell -NoProfile -ExecutionPolicy Bypass -File "<PORTABLE_ROOT>\START_AAYS_ON_ANY_WINDOWS_PC.ps1"`
