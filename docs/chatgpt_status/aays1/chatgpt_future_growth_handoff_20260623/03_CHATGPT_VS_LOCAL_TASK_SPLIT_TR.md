# Task Split

## ChatGPT'ye verilecek isler

1. Backend schema patch'i
2. Backend service patch'i
3. Frontend popup/panel binding patch'i
4. Disclaimer ve probability contract duzeltmesi
5. Local smoke checklist metni
6. Final wrapper oncesi acceptance checklist metni
7. Gerekirse `apply_patch` bloklari

## Lokal makinede yapilacak isler

1. Docker'in gercekten ayaga kalkmasi
2. `http://127.0.0.1:8010/api/future-growth/layer?...` timeout'unun bitirilmesi
3. shared runner / local queue zinciri dogrulamasi
4. `main` ile gercek Future Growth runtime kokunun uyusturulmasi
5. final wrapper raporunun yalniz gercek gecis sonrasi yazilmasi

## Codex'te kalmasi gereken isler

1. Gerekirse lokal repo/worktree duzeltmesi
2. Gerekirse app-open veya runtime import engeli
3. ChatGPT patch'lerinin gercek repoya uygulanmasi ve son lokal smoke
