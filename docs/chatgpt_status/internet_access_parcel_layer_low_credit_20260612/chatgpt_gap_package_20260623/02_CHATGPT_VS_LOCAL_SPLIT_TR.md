# ChatGPT vs Local Split

## ChatGPT'nin yapabilecegi isler

1. Parcel-level pipeline tasarlamak
2. Yeni script iskeletleri yazmak
3. SQL / CSV / GeoJSON / JSON schema tasarlamak
4. Frontend popup ve right-panel contract alanlarini tanimlamak
5. Patch diff veya full-file taslagi vermek
6. Acceptance checklist yazmak
7. D/F drive klasor yapisini planlamak

## ChatGPT'nin yapamayacagi isler

1. F drive'daki buyuk dosyalari gercekten uretmek
2. DB import calistirmak
3. Local 8010 endpoint smoke gerceklestirmek
4. Browser icinde gercek thematic parcel layer goruntusunu dogrulamak
5. PostGIS tablosunun gercek durumunu okumak
6. Buyuk GeoJSON/CSV dosyalarini F/D uzerinde tasimak

## Local operator veya Codex gereken isler

1. PowerShell ile F/D klasorlerini acmak
2. Buyuk artefact uretimini calistirmak
3. DB import veya join pipeline calistirmak
4. `/map/internet-access` endpoint probe
5. Browser smoke
6. Final dosyalarin gercekten parcel geometry tasiyip tasimadigini kontrol etmek

## Dogru is bolumu

- ChatGPT:
  - metin, patch, script, schema, runbook
- Local:
  - execution, ETL, DB, large file, smoke
