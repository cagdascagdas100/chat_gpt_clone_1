## Final editorial decision
The comment is resolved with a reduced evidence-based figure plan. The auditable project package contains three high-resolution composite images of existing application screens, but it does not contain an original landing-page screenshot or an original personal-input form screenshot. Missing screens will not be recreated, digitally simulated, or presented as original evidence.

The Word package contains the following high-resolution composite images:
- `image16.jpg` — 2987 × 2065 pixels: section selection, machine selection/detail, and a risk-dashboard panel;
- `image17.jpg` — 2982 × 2069 pixels: Precautions, My Legal Rights, and Visual Results;
- `image18.jpg` — 2983 × 2052 pixels: What If No Precautions? and Cost Analysis screens.

The package also contains `image15.jpg` — 4957 × 7015 pixels — which is a workflow schematic showing personal-risk inputs and the work/machine hierarchy. It is not an application screenshot and must be captioned as an illustrative workflow diagram.

## Missing evidence
No original high-resolution image was found for:
- the application landing or opening page;
- the personal-information input form;
- a corrected dashboard in which the unsupported overall-risk label and scalar have already been removed.

The absence of these assets must not be hidden by generating substitute screenshots.

## Locked figure plan
1. Retain the workflow schematic as a diagram of the input path, not as an interface screenshot.
2. Use the first two panels of `image16.jpg` to document section selection and machine selection/detail.
3. Omit or crop the right-hand `Overall Risk` dashboard panel from `image16.jpg` because its scalar and label conflict with the finalized decisions under Comments 17, 18, and 20.
4. Retain `image17.jpg` only after the manuscript caption identifies the three screens separately: precautions, legal-information content, and body-region visualization.
5. Use the `What If No Precautions?` and Cost Analysis panels from `image18.jpg` only if the labels and formulas remain consistent with the corrected payment-day and cost terminology under Comments 8, 9, and 21; otherwise omit the affected cost panel.
6. Do not add a landing-page or personal-input screenshot unless the original application export is later supplied.

## Captioning rule
Each panel must be described in a separate sentence and must state exactly which part of the workflow it documents. The figures are interface illustrations, not usability, effectiveness, or field-validation evidence.

## Restoration rule
An additional landing-page or personal-input figure may be added only from an original application capture with legible text, known capture date/version, and no digitally reconstructed content.

## Status
Fully finalized. The reviewer request is answered by expanding the application documentation only with verified existing screens and by explicitly declining to fabricate unavailable interface evidence.
