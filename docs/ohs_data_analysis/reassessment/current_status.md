## Latest decision — Comment 20
The reported `50.62%` is arithmetically reproducible but is not a validated overall-risk percentage. The example first produces separate within-region values using normalized exponential rank weights with `alpha = 0.8`: head 50.56, arms 56.48, legs 49.49, and torso 25.57. Sorting these four values and applying a second cross-region decay with `alpha = 0.60` yields 50.619..., which was reported as 50.62%.

## Relationship to the 10/90 claim
The 50.62 value is not generated by the 10% internal / 90% external weighting. They are separate unsupported procedures placed in the same paragraph:
- 50.62 comes from cross-region `alpha = 0.60` aggregation;
- 10%/90% comes from the internal–external composite rejected under Comment 17.

## Final correction
- Delete the `overall risk of 50.62%` statement and all related overall percentages.
- Delete the claim that the method calculates `accurate risk percentages`.
- Retain regional values only as separate priority-score illustrations on the input scale, without percent signs or personal-risk interpretation.
- Do not calculate a replacement cross-region average or weighted total without a reproducible and validated rule.
- Note that the example includes only four regions despite claiming five and provides no missing-region rule.
