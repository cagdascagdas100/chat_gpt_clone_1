# Comment 20 — Remove unsupported 50.62% overall-risk value

## Reviewer comment
`Bunun yukardaki 90/10 ile bağlantısı var sanırım. Yine karmaşık bir durum, verilecekse böyle bir şey açalım.`

## Reassessment finding
The reported `50.62%` is mathematically reproducible, but it is not a validated overall-risk estimate. It is generated by a second, unsupported aggregation layer.

Using the manuscript's within-region normalized exponential rank weights with `alpha = 0.8`, the example inputs yield:

- head: 50.56;
- arms: 56.48;
- legs: 49.49;
- torso: 25.57.

After sorting these four regional values and applying a second normalized exponential weighting with `alpha = 0.60`, the result is 50.619..., reported as `50.62%`.

## Critical interpretation
The 50.62 value is not mathematically produced by the separate 10% internal / 90% external weighting. The two claims occur in the same paragraph, but they represent different unsupported aggregation procedures:

1. `50.62%` comes from cross-region weighting with `alpha = 0.60`;
2. the 10%/90% statement comes from the separate internal/external composite rejected under Comment 17.

## Validity problems
- No empirical, expert-elicitation, legal, optimization, sensitivity, or validation record supports the cross-region `alpha = 0.60`.
- The manuscript states that five body regions are combined, but the numerical example supplies only four regions and gives no missing-region rule.
- Anatomically distinct regional values are not shown to be commensurable components of a single validated scale.
- The result is a deterministic transformation of illustrative inputs, not an observed risk rate, calibrated probability, or validated percentage.
- The phrase `accurate risk percentages` is unsupported.

## Final decision
- Delete the `overall risk of 50.62%` statement.
- Delete all publication- and application-facing overall percentages derived from cross-region `alpha = 0.60` aggregation.
- Keep the Comment 17 removal of the separate 10%/90% internal–external composite.
- Report retained regional values separately.
- If the numerical example is retained, label it only as an arithmetic illustration of region-specific priority-score calculation on the input scale; do not append a percent sign or interpret it as individual or overall occupational risk.

## Approved replacement
`For the illustrative inputs, the within-region calculation produced separate priority-score values of 50.56 for the head, 56.48 for the arms, 49.49 for the legs, and 25.57 for the torso. These regional values are reported separately. No cross-region overall percentage was calculated because the study materials did not provide a validated rule for combining anatomically distinct regional scores, and the example did not specify an input or missing-value rule for every predefined region.`

## Cross-comment consistency
This decision implements the weighting constraints established under Comments 16–18 and prevents the removed 10%/90% composite from being conflated with the separate cross-region aggregation.
