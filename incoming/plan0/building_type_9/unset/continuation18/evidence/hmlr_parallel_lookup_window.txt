OFFICIAL PUBLIC NO-LOGIN SOURCE WINDOW — HM Land Registry, GOV.UK identifier lookup datasets
Checked 2026-09-29 UTC.

Primary: https://www.gov.uk/government/statistical-data-sets/transaction-unique-identifier-and-inspire-id-look-up-table-dataset
Companion technical route: https://www.gov.uk/government/statistical-data-sets/technical-specification-transaction-unique-identifier-and-uprn-look-up-table-dataset

The official HMLR Transaction unique identifier and INSPIRE ID Look Up Table contains the Price Paid transaction
unique identifier plus INSPIRE ID for freehold registered property where an index polygon exists. HMLR states that
INSPIRE Index Polygons are open-source locations/indicative extents of freehold registered property, and INSPIRE_ID
is the unique polygon identifier.

The official HMLR Transaction unique identifier and UPRN Look Up Table technical specification states that the
same Price Paid transaction identifier can be linked to a UPRN where HMLR can make a reliable relationship between
the registered title address and an addressable location. UPRN is the identifier of that addressable location.

MATERIAL METHOD CHANGE:
Previous window: OS Open Linked Identifiers UPRN→TOID.
This window: HMLR parallel transaction-key lookups, Transaction→INSPIRE polygon ID and Transaction→UPRN.
For qualifying published sales, the shared transaction identifier supplies a documented indirect INSPIRE polygon↔UPRN bridge.

Remaining acceptance gap:
The project canonical_parcel_id inventory/polygons are not present in this public window, and no deterministic
canonical_parcel_id↔INSPIRE_ID (or canonical_parcel_id↔transaction identifier) mapping is available here.
Therefore CLASSIFY_ALL cannot safely classify a project canonical parcel as BUILDING_PRESENT/VERIFIED_NO_BUILDING
or populate a building type from this source window alone.
