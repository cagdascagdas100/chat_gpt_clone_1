OFFICIAL PUBLIC NO-LOGIN SOURCE WINDOW — Ordnance Survey OS Open Linked Identifiers, National Data Library/data.gov.uk
Checked 2026-09-29 UTC.

Publisher: Ordnance Survey. Last updated: 23 June 2026.
The official catalogue states that OS Open Linked Identifiers provides authoritative relationships between UPRNs,
USRNs and TOIDs for reliable matching. It explicitly describes linking address-related data with a building footprint.
The catalogue provides links to the Open Linked IDs technical specification and OS DataHub Open IDs.

This is a materially different binding method from the preceding OS MasterMap TopographicArea schema-only route:
it introduces the authoritative UPRN↔TOID linkage needed to bridge an addressable property identifier to a graphical
building object. The remaining project-specific gap is upstream: this public source window does not expose the
project canonical_parcel_id inventory/polygons or a canonical_parcel_id↔UPRN relationship. Without that exact
canonical binding, no parcel record can satisfy CLASSIFY_ALL acceptance requirements.
