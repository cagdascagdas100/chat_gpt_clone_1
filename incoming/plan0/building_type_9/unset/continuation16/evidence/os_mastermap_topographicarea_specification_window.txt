OFFICIAL PUBLIC NO-LOGIN SOURCE WINDOW — Ordnance Survey OS MasterMap Topography Layer / TopographicArea technical specification
Checked 2026-09-29 UTC.

Official OS documentation states that TopographicArea represents polygon-based topographic objects such as buildings. Each feature has a unique TOID/gml:id. The descriptiveGroup attribute is the primary classification and can classify topographic features as Building. The feature-code lookup documents Building / Area as feature code 10021.

This materially changes the method from the prior VectorMap Local sample-window route: it uses the authoritative OS MasterMap TopographicArea schema and identifier/classification model rather than sample product outlines. However, this public no-login documentation window does not expose the project's canonical parcel polygons and does not establish a deterministic canonical_parcel_id-to-TOID binding. Consequently it cannot produce a valid canonical parcel record under CLASSIFY_ALL. No parcel is accepted.
