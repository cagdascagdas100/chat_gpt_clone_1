OFFICIAL PUBLIC NO-LOGIN SOURCE WINDOW — Ordnance Survey OS Open TOID
Checked 2026-09-29 UTC.

OS Data Hub describes OS Open TOID as an open dataset giving a generalised location to key features in OS MasterMap
premium products, allowing third-party data linked to the corresponding TOID to be visualised.
Coverage can be selected; data are vector; supply formats are CSV and GeoPackage; version date is August 2026.
OS states that OpenData downloads are available under the Open Government Licence.

This materially changes the preceding OS Open Linked Identifiers relationship-only route to an open TOID location product.
However, no deterministic project canonical_parcel_id-to-TOID crosswalk is present in the available evidence.
The product description is for generalised locations, not proof of the required canonical parcel Polygon/MultiPolygon,
and it does not establish both a real building footprint and proven building type for a canonical parcel.
No parcel is therefore accepted.
